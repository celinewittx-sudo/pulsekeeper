# Pulsekeeper 节拍器

一个面向手机的离线 Web 节拍器。它不是对任何现有产品的复制，而是采用了专业练习节拍器常见的操作方式：BPM、拍号、细分、重音、Swing、静音练习、Tap Tempo 和触觉反馈。

## 在电脑上预览

直接双击 index.html 可以查看界面；不过浏览器只有在 localhost 或 HTTPS 下才会启用完整的 PWA 安装和离线缓存功能。

如果已安装 Node.js，可在这个目录运行 npx serve . -l 4173，然后打开 http://localhost:4173。

## 在安卓上使用

把本目录部署到任意 HTTPS 静态托管服务（例如 GitHub Pages、Cloudflare Pages 或 Netlify），在 Android Chrome 打开该网址后：

1. 点击页面右上角的安装图标；若它没有显示，打开 Chrome 菜单。
2. 选择“安装应用”或“添加到主屏幕”。
3. 首次点击“开始”时允许网页播放声音。

安装后应用可离线打开。浏览器和系统对后台音频、振动、屏幕常亮的限制会因设备省电策略而不同。

## 功能

- 20–320 BPM，滑杆、加减键与 Tap Tempo
- 1–12 拍的拍号、2/4/8/16 拍单位
- 八分、三连音、十六分细分；二等分 Swing
- 每一拍可设为常规、重音或静音
- 木质、电子、铃音三种合成 click；音量控制
- 强拍振动、静音练习和屏幕常亮（浏览器支持时）
- 本机自动保存设置，PWA 离线缓存
